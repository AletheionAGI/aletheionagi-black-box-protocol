# Security policy

Do not open a public issue containing an API key, cookie, HAR file, private response,
unsanitized evidence package or real customer data.

The runner is designed to persist only request/response bodies, status, duration and
correlation IDs. It does not persist Authorization headers. Before sharing evidence,
inspect every file and any separately captured screenshot.

If a foreign canary appears, stop testing, preserve the sanitized evidence package and
contact AletheionAGI through the private security channel published by the organization.
Do not post the response publicly before coordinated review.
